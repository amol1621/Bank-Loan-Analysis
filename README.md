
# 🏦 Bank Loan Analytics Dashboard | Power BI

An interactive **Bank Loan Analytics Dashboard** built in **Power BI** to analyze loan applications, funding performance, customer demographics, approval trends, and repayment status. This project transforms raw loan data into actionable business insights through dynamic visualizations and KPI tracking.

---

## 📌 Project Overview

This dashboard provides a comprehensive analysis of loan application data, helping stakeholders monitor portfolio performance, identify customer trends, and evaluate loan approval and repayment behavior.

---

## 🎯 Objectives

* Analyze loan applications and customer profiles
* Monitor funded and received loan amounts
* Compare approved and rejected loan applications
* Analyze loan repayment status
* Identify trends across loan purposes and customer demographics
* Evaluate credit score impact on loan approvals
* Build an interactive executive dashboard for decision-making

---

## 📂 Dataset

The project uses a loan application dataset containing customer demographics, loan details, credit history, approval status, and repayment information. Additional fields such as **Funded Amount**, **Amount Received**, and **Loan Repayment Status** were generated for analytical and educational purposes to simulate a complete banking scenario.
